AI COLLEGE PROBLEM RADAR - SIMPLE WEBSITE

Files:
- index.html : main website
- style.css  : design and responsive layout
- script.js  : complaint submission, demo AI classification, tracking and login
- admin.html : demo admin dashboard

HOW TO RUN:
1. Extract the ZIP.
2. Double-click index.html, or open it in VS Code and use Live Server.
3. Submit a complaint. It will be stored in browser localStorage.
4. Admin Login demo: username admin, password admin123.
5. This is a frontend prototype. For real deployment, connect a backend API, database, authentication, file storage, and real AI model.
